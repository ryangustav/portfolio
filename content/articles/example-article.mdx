This is a **template**. Copy this file, rename it (the filename becomes the URL slug,
e.g. `my-first-writeup.mdx` → `/en/articles/my-first-writeup`), change the frontmatter,
and remove `draft: true` when it's ready to publish.

## Headings, lists and quotes

Use `##` for sections and `###` for subsections.

- Recon
- Exploitation
- Privilege escalation

> **Defensive takeaway:** close every write-up with how to detect or prevent the issue.

## Code blocks

Code fences get syntax highlighting. Add a title and highlight lines with `{n}`:

```ts title="middleware.ts" {3-4}
export function middleware(req: NextRequest) {
  const res = NextResponse.next();
  res.headers.set('X-Frame-Options', 'DENY');
  res.headers.set('X-Content-Type-Options', 'nosniff');
  return res;
}
```
